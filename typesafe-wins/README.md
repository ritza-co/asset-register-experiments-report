# TypeSafe wins on a batched asset register

Across six runs, TypeSafe scored 408/432 (94.4%) and returned the same 68/72 answers every time. Luna scored 319/432 (73.8%) and varied from 26/72 to 72/72.

TypeSafe was also 32.4 times faster by measured wall time.
